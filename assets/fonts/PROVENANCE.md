Rajdhani Bold by the Indian Type Foundry, from github.com/google/fonts (ofl/rajdhani), licensed under the SIL Open Font License 1.1 (see OFL.txt).

Chakra Petch SemiBold by the Chakra Petch Project Authors, from github.com/google/fonts (ofl/chakrapetch/ChakraPetch-SemiBold.ttf), licensed under the SIL Open Font License 1.1 (see OFL-ChakraPetch.txt).

Big Shoulders Stencil Display Black by the Big Shoulders Project Authors, from github.com/google/fonts (ofl/bigshouldersstencildisplay), licensed under the SIL Open Font License 1.1 (see OFL-BigShouldersStencilDisplay.txt). The upstream file is the variable font `BigShouldersStencilDisplay[wght].ttf`; the static Black (900) instance used here was made with:

    uvx --from fonttools fonttools varLib.instancer "BigShouldersStencilDisplay[wght].ttf" wght=900 -o BigShouldersStencilDisplay-Black.ttf

Rajdhani's license text is OFL.txt; each other font has its own OFL-<Font>.txt.
