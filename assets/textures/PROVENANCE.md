# Texture provenance

All textures are original, generated on 2026-11-25 with the Codex CLI (`codex exec`, built-in
image generation), then resized to 1024×1024 with ImageMagick. Common prompt frame:

> Use your image generation tool to create a seamless, tileable, top-down texture: {subject}.
> Square, evenly lit with no lighting gradient or vignette, no text, no logos, no people. The
> left/right and top/bottom edges must tile seamlessly.
